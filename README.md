# 项目检查点排期组件

此目录包含公开的静态界面程序，用于在飞书应用中嵌入项目排期与检查点界面。项目记录及打卡数据由飞书提供，本目录不包含业务数据。

将本目录的全部六个文件上传到 GitHub 仓库根目录，并将 GitHub Pages 的发布来源设为该分支根目录。index.html、两个 JavaScript 文件和 CSS 文件必须保持同级，不要再放入 assets 子目录。`.nojekyll` 用于直接提供静态文件。

正式使用须通过飞书应用内已配置的数据源和权限打开。单独打开网页不会获得飞书项目数据；`?demo=1` 仅为本地内存中的示例演示，不是真实业务记录。

静态发布成功不代表每位成员均可访问；正式替换飞书组件服务地址前，需验证成员设备能够访问新的 HTTPS 地址。
